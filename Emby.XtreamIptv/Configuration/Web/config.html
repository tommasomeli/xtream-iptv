Xtream server

Base URL of the Xtream account, without a trailing slash. With Dispatcharr, this is its Xtream output address.
Sent on every request to the Xtream server. Leave empty unless the provider requires a specific player string.

Dispatcharr

Reads channel profiles, stream stats and Gracenote station IDs from Dispatcharr.
Turn off to make sure every stream goes through Dispatcharr.
With the proxy, Dispatcharr lists Emby as an anonymous client. The Xtream option plays through the account above, so Dispatcharr shows that user and applies its stream limits. It only takes effect when the Xtream server is the Dispatcharr server.
The Xtream server URL and the Dispatcharr URL are not the same address, so the proxy will still be used.
Change this only if a Dispatcharr channel plays with the wrong codec.

Channel profiles

Only channels enabled in at least one ticked profile appear in Emby. Tick none to show all channels.
Click "Refresh profiles" to load.

Live TV

Serves the Xtream channels to the Emby tuner.

Channels

Tick the Live TV categories to include. Tick none to include every channel.
Click "Refresh categories" to load.
Removes quality tags and the terms below from channel names.

Guide

Custom URL: any XMLTV feed, for example Dispatcharr's /output/epg. Disabled: no guide from this plugin, use it when an XMLTV source is already set in Emby's Live TV settings.
Turn off without Emby Premiere.

Playback

MPEG-TS gives the lowest latency.
Shows DVB subtitles in Emby. Channels without them get an empty subtitle track.
Converts AC3 and EAC3 to AAC. Fixes silent audio on iPhone and iPad, but disables Dolby passthrough elsewhere.
0 = no cap. Set it below the hardware encoder limit (for example 8) when transcoding falls back to software with "Bitrate exceeds maximum supported rate".

Maintenance

Guide mappings are synced automatically after every channel refresh. Run it by hand only if Gracenote guide data stopped showing for Dispatcharr channels.

Catalogue

Movies and series from the Xtream lists are added straight to the Emby libraries below, without files. Series episodes and movie detail are loaded when a title is opened. A daily scheduled task keeps the lists up to date; Sync now runs it immediately.
Two empty folders, Movies/ and Shows/, are created inside it: they are the locations of the two Emby libraries and stay empty.

Movie categories

Tick the categories to sync. Tick none to sync every movie category.
Click "Refresh categories" to load.

Series categories

Tick the categories to sync. Tick none to sync every series category.
Click "Refresh categories" to load.

Options

Keeps titles flagged as adult and categories with adult words in their name.
When you have picked categories below, a movie or series category the provider adds later (a new saga, a new channel of films) joins your selection at the next sync instead of staying out. Categories matching the excluded terms never join.
Releases of the same title that differ only by quality tag become one movie with a version picker.
Plot, cast and backdrop of a movie, and the cast and episodes of a series, are fetched from the provider the first time the title is opened. The sync writes titles only.
Xtream has no actor photos. When a title is opened, the actors of its cast that have none yet are refreshed in the background by Emby's own person providers (TheMovieDb), at most 15 per title, three at a time; the open page refreshes when they land. Each actor is fetched once and shared by every title.
The detail page waits this long for the provider so it opens complete. Past it the page opens with what is there and refreshes by itself when the detail arrives.
Movie and series categories whose name contains one of these terms are skipped, whatever the selection below; their titles are removed at the next sync.
Removed in addition to the built-in quality tags (FHD, 4K, HEVC, 1080p and so on).
A sync never removes more than this share of the existing titles in one run, so a provider glitch cannot empty the library.
